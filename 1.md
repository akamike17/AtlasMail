# ATLASMAIL — ESPECIFICACIÓN MAESTRA
## Servidor empresarial de correo, colaboración, seguridad y administración

PROYECTO NUEVO DESDE CERO.

Nombre:
AtlasMail

Objetivo:
Construir una plataforma empresarial self-hosted de correo y colaboración.

NO construir únicamente:
- un cliente POP3;
- un webmail;
- una interfaz encima de Gmail;
- un SMTP relay;
- un CRUD de correos.

AtlasMail debe convertirse progresivamente en una plataforma comparable
conceptualmente a una solución empresarial tipo Exchange:

MAIL
+ DOMINIOS
+ BUZONES
+ SMTP
+ IMAP
+ WEBMAIL
+ CALENDARIO
+ CONTACTOS
+ GRUPOS
+ REGLAS
+ ANTISPAM
+ SEGURIDAD
+ AUDITORÍA
+ BACKUP
+ BÚSQUEDA
+ ADMINISTRACIÓN
+ API
+ AUTOMATIZACIÓN
+ IA OPCIONAL

Debe poder instalarse y administrarse en infraestructura propia.

Prioridades:

SEGURIDAD
> INTEGRIDAD DEL CORREO
> INTEROPERABILIDAD
> RECUPERACIÓN
> ADMINISTRACIÓN
> UX
> FUNCIONES AVANZADAS

No afirmar compatibilidad que no haya sido probada.
